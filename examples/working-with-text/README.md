Text manipulation scenarios aligned with the "Working with Text" docs. All
scripts operate on `examples/Showcase.pdf` and emit results to
`output/working-with-text/`.

- `01_replace_text_using_selector.py` – replace literal text using a selector.
- `02_delete_text_using_selector.py` – delete literal text using a selector.
- `03_insert_text_after_match.py` – insert text after a matching phrase.
- `04_style_text_using_selector.py` – style matching text with a selector.
