Image manipulation scenarios aligned with the "Working with Images" docs.
Every script uses `examples/Showcase.pdf` and writes results to
`output/working-with-images/`.

- `01_list_images.py` – list image metadata and coordinates.
- `02_move_image.py` – reposition the first page image.
- `03_delete_images.py` – remove all images from a page.
- `04_scale_image.py` – scale the first image on page 1.
- `05_rotate_image.py` – rotate the first image on page 1.
- `06_crop_image.py` – crop the first image on page 1.
- `07_set_image_opacity.py` – change the opacity of the first image.
- `08_flip_image.py` – flip the first image horizontally or vertically.
- `09_replace_image.py` – replace the first image with `examples/experiment.png`.
- `10_move_scale_rotate_and_flip_image.py` – chain multiple image transformations.
