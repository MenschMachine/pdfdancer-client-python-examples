Template filling scenarios aligned with the "Working with Templates" docs. All
scripts use template PDFs from this directory and emit results to
`output/templates/`.

- `01_basic_fill.py` – fill placeholders with dynamic content.
- `02_page_level_fill.py` – fill placeholders on specific pages only.
- `03_reflow_text.py` – use ReflowPreset for longer replacement text.
- `04_mail_merge.py` – generate multiple documents from a single template.

Template PDFs:
- `Template.pdf` – single-page certificate template with placeholders.
- `MultiPageTemplate.pdf` – multi-page document with per-page placeholders.
