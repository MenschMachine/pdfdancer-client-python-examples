Path manipulation scenarios using `examples/basic-paths.pdf`. Scripts that
modify the PDF write results to `output/working-with-paths/`.

- `01_list_paths.py` – list paths on page 1.
- `02_group_and_move_paths.py` – group paths and move the group.
- `03_scale_path_group.py` – group paths and scale the group.
- `04_rotate_path_group.py` – group paths and rotate the group.
- `05_remove_path_group.py` – remove a grouped set of paths.
- `06_change_path_colors_and_move.py` – change path colors and position.
